# Dixon-Coles Football Forecast Demo

Run:
    pip install -r requirements.txt
    python dc_demo.py

Output: demo match probabilities (H/D/A), top-5 correct scores, and a
walk-forward backtest on the 2020-21 Premier League season.

Data: open historical EPL dataset (6 seasons), in /data.
Demo only - no live APIs, odds, team news, n8n or Telegram.

## Web app
    pip install -r requirements.txt
    streamlit run app.py
